# Code of Conduct

## Expectations

Everyone participating in this project's issues, pull requests, reviews, or other
project spaces should be treated respectfully, regardless of background,
identity, experience, or ability. Be constructive, assume good faith where
reasonable, accept feedback, and focus criticism on work rather than people.

Harassment, discriminatory language, threats, sexualized attention, doxxing,
deliberate disclosure of private data, and repeated disruptive behavior are not
acceptable. Do not publish another person's usage history or identifying details.

## Reporting and Enforcement

For a non-sensitive moderation concern, use the
[repository issues](https://github.com/idvoretskyi/token-budget/issues) and request
maintainer review without repeating abusive or private content. For confidential
abuse reports, use [GitHub's reporting tools](https://docs.github.com/en/communities/maintaining-your-safety-on-github/reporting-abuse-or-spam).
This project does not currently advertise a separate private conduct-reporting
address. Security vulnerabilities belong in the private channel described in
[SECURITY.md](SECURITY.md), not in public moderation discussions.

Maintainers may edit or remove content, lock discussions, warn participants, or
temporarily or permanently restrict participation according to severity and
repeated behavior. Reports should be handled with discretion; do not promise
confidentiality for content posted publicly. Retaliation against good-faith
reporters is itself unacceptable.
